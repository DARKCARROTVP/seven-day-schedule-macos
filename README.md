# 七日日程（Seven Day Schedule）

一款轻量、原生的 macOS 菜单栏日程组件，用一个紧凑窗口集中展示从今天开始 7 天内的安排。数据仅保存在本机，支持系统通知、每周循环和开机自动启动。

## 主要功能

- **未来 7 天视图**：按天展示从今天开始连续 7 天的日程和数量。
- **日程增删改**：新建日程后，可点击整条日程卡片直接编辑，也可以使用右侧编辑与删除按钮。
- **自定义提前提醒**：支持设置在日程开始前 `X` 分钟通过 macOS 系统通知提醒。
- **每周循环日程**：日程可设置为每周重复；之后会在同一星期、同一时间展示并提醒。
- **周期日程管理**：编辑或删除每周日程时，会作用于整个重复系列。
- **开机自动启动**：首次运行后自动注册为登录项，也可在应用设置中随时关闭。
- **菜单栏常驻**：应用不占用 Dock，点击菜单栏日历图标即可快速展开或收起。
- **本地数据存储**：日程保存在用户的 Application Support 目录，不依赖网络或云服务。

## 系统要求

- macOS 13 Ventura 或更高版本
- Apple Silicon 或与本地 Swift 工具链兼容的 Mac
- 构建时需要 Swift 5.10 和 macOS Command Line Tools

## 安装

1. 从项目的 Releases 页面下载 `SevenDaySchedule-macOS.zip`。
2. 解压后，将“七日日程.app”移动到“应用程序”文件夹。
3. 首次打开时允许通知权限。
4. 点击菜单栏中的日历图标开始使用。

> 本项目使用本机临时签名构建。如果 macOS 阻止首次打开，可在“系统设置 → 隐私与安全性”中确认打开。

## 使用说明

### 新建普通日程

点击右上角“新建”，填写标题、开始时间、提前提醒分钟数和可选备注，然后保存。

### 编辑或删除日程

- 点击日程内容块，直接打开编辑窗口；
- 点击铅笔按钮也可编辑；
- 点击垃圾桶按钮删除日程。

### 创建每周循环日程

新建或编辑日程时开启“每周重复”。该日程会从所选日期开始，在以后每周同一天、同一时间出现，并使用相同的提前提醒设置。

## 数据位置

日程数据保存在：

```text
~/Library/Application Support/com.codex.SevenDaySchedule/schedules.json
```

卸载应用不会自动删除该文件，因此重新安装后仍可读取原有日程。

## 从源码构建

在项目根目录执行：

```bash
chmod +x work/build.sh
./work/build.sh
```

构建结果位于：

```text
outputs/七日日程.app
```

构建脚本会完成 Swift 编译、应用图标生成、临时签名和签名校验。

## 项目结构

```text
work/
├── ScheduleBar.swift    # 应用数据、提醒、登录项和 SwiftUI 界面
├── Info.plist           # macOS 应用配置
├── IconGenerator.swift  # 应用图标生成器
└── build.sh             # 一键构建脚本
```

## 隐私

应用不会上传日程、备注或使用数据。除 macOS 系统通知和登录项服务外，不连接任何网络服务。
